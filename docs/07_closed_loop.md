# 07：闭环测量、时序和故障

物理步/命令更新 2 ms，MPC 20 ms，整数 stride=10。配置拒绝非整数周期比；不用浮点取模。IK 只在目标激活时同步触发，有迭代和墙钟预算，因此激活 tick 可能超过 20 ms；仿真时间量化和墙钟延迟必须分别报告。

正常顺序：mj_step1 更新当前派生量 → 读取 q/dq/site/Jacobian → MPC tick 消费到期事件/IK/优化 → 从上一参考边界桥接 → 高频采样及 nominal 前馈 → JointCommand → MIT 限幅并写 ctrl → 注入外力 → mj_step2。行日志使用步前 t，对应全部实际状态和本步发送命令；实测加速度是相邻步前 qvel 后向差分，首行 NaN，不是优化输入。

旧计划/目标在新事件出现时失效，保留真实状态、上一参考边界以及已到达历史。相同 tick 的所有到期事件中，只激活 scheduled_time 最新者，同时间按输入顺序后者优先。记录被覆盖者 superseded、不为它们做 IK。reached 仍保持；后来抢占保留其 reached 事实。

IK 失败把最新目标记为 rejected，旧 q_goal 不再进入代价；从连续参考有界制动，到低速保持。QP 失败/预测接触也制动并记录，连续失败超过 max_failures 停止。无合法桥接制动则停止，不造合法数组。过期命令在 compose 中进入显式故障阻尼 -Kd*dq，不延用旧前馈/加速度；该行为不宣称参考连续。

监测实际越机械界、非有限状态、非允许接触、持续饱和及 MuJoCo warning。每一步比较预期整数 tick 时间，识别自动 reset 引起时间跳变；停止保存日志，不能把 reset 当恢复。

预测与物理差异来自参考桥接、有限内环增益、离散积分、动力学耦合、饱和与外力。预测 q_pred[1] 与下一实测 q/dq 的误差单独记录。MPC 优化仍用实际状态，不能拿连续参考冒充测量。接触检查为离散预测样点和实际接触，漏过段内接触的可能性仍在，无全局避障保证。

已测：事件合并和 reached 历史、参考端点/内部界、过期力矩、失败计数停止。未测：真实切换时非零速度连续、扰动后恢复、模型 reset 监测的真实引擎行为。例子 `python examples/04_trace_replan.py` 在依赖安装后导出实际数据流；目前未成功运行。

常见错误：将 IK 虚拟步视为物理运动、用 scheduled time 冒充 activated time、只报 QP 时间宣称实时。练习：构造同一 tick 三个事件，确认只有最后一个出现 IK 耗时，同时前三条历史仍可追溯。
