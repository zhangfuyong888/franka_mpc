# 10：当前限制与后续顺序

真实headless保持、单目标到达、切换/回放、随机、快速切换、无效目标制动以及外力对照已验证。22项测试在warnings作为错误时通过，见validation.md。剩余环境限制是工具进程无法连接X11，GUI自动验收未完成；干净环境安装与完整传递依赖锁仍未验证。

算法边界也独立存在：IK 是局部数值求解，无全局可达性证明；关节路径的末端通常不直；有限时域硬界不保证递归可行；离散预测接触监测不是连续全局避障；桥接只 C1，加速度能跳变，无硬 jerk/力矩预测约束；真实内环偏差、摩擦、采样和饱和可能导致预测误差或稳态偏差。

随机目标替换是在线重新规划，轨迹跟踪是执行有时间参考，参数自适应还需要未知动力学的估计/更新律。本项目只有前两者，未实现参数自适应。MIT 内反馈会自行抵抗扰动，恢复不能全部归于 MPC。

优先三项：

1. 完成干净环境依赖锁与GUI验收，扩大少量固定seed回归。
2. 依据真实日志继续改进参考/实际偏差和目标激活时IK尾延迟；不可达目标拒绝tick仍可能超20ms。
3. 在已验证版本上加入更准确的内环预测、jerk/力矩约束或有界终端制动条件，再考虑任务空间 MPC、辨识、障碍物规划和硬件适配。

不为仿真任务增加 ROS、CAN、Web 后端、RL 或真实驱动。未来硬件另建适配器，重新评估通信、限幅、接触和安全条件，不能直接部署本项目代码。
