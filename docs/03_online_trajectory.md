# 03：在线轨迹与参考桥接

路径描述经过哪些构型，轨迹还包含时间、速度与加速度。目标给位置，IK 给终点，MPC 从实测 q/dq 在线优化。没有必须执行完的全程多项式；末端经 FK 得到的路径通常不是笛卡尔直线。

第一预测段理想参考为 $q^{ideal}(s)=q_0+v_0s+\frac12a_0s^2$，$v^{ideal}(s)=v_0+a_0s$。实际跟踪有误差时，直接用新测量重新锚定命令会跳变。ReferenceGenerator 保留上一已接受参考边界 $(q_s,v_s)$，连接当前预测第一步 $(q_e,v_e)$。

令 $q(s)=c_0+c_1s+c_2s^2+c_3s^3$，四个端点条件解得

$$c_0=q_s,\ c_1=v_s,\ c_2=3(q_e-q_s)/T^2-(2v_s+v_e)/T,$$
$$c_3=-2(q_e-q_s)/T^3+(v_s+v_e)/T^2.$$

解析速度为 $c_1+2c_2s+3c_3s^2$，加速度为 $2c_2+6c_3s$。q/dq 在正常边界 C1，加速度允许跳变，不保证 C2 或硬 jerk。

ReferenceSegment.extrema 解速度二次方程查位置极值，解加速度一次方程查速度极值，加速度查端点。所有实根限定在段内；不能只查端点。已测 q(0)=q(1)=0、v(0)=2、v(1)=-2 的曲线，解析内部最大位置 0.5，正确拒绝越界段；解析导数也由有限差分核验。

不合法时，从同一边界构造 $a_b=\operatorname{clip}(-v_s/T,\pm a_{max})$ 的恒加速度制动端点。混合候选与制动端点，alpha 依次 1、0.5、0.25、0.125、0，每次重建曲线并完整检查。禁止逐样本裁剪 q_des/dq_des。无合法制动段抛 ReferenceFailure、停止保存日志；故障阻尼不纳入正常连续性结论。

`python -m pytest -q tests/test_core.py -k 'hermite or reference'` 已验证边界、内部极值、回退和停止。真实桥接频率/预测误差仍未测。频繁回退应检查内环误差、前馈、饱和和采样。练习：构造端点都合法但内部速度超界的曲线。
